# Haniy Turana Portfolio v3

This version prioritises a retail Space & Range case study, keeps the site mobile responsive, and links to existing live technical projects.

## Open locally
Open `index.html`, or use the VS Code Live Server extension.

## Publish on GitHub Pages
1. Create a repository such as `haniyturana.github.io` or `portfolio`.
2. Upload all files and folders from this package.
3. In GitHub: Settings > Pages > Deploy from a branch > main / root.

## Important
The Space & Range dashboard uses synthetic data and is clearly labelled as an independent case study. Replace the resume PDF when needed, but keep the same file name or update its link in `index.html`.
